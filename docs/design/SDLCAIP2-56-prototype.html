對照說明

1. <h4> 文字移除「🎤 」前綴（AC1）。
2. #speaker-rename-area 背景/邊框/圓角改為 --ds-surface / --ds-border / --ds-radius-md（比照全站 .card 同組 token），h4 顏色改 --ds-text-secondary，不留任何綠色/強調色（AC2， 回應第一輪 G1 退回意見）。
3. .rename-row input 邊框改 --ds-border-strong、圓角 --ds-radius-sm、高度改用固定 --ds-control-h-desktop （手機 --ds-control-h-mobile），padding 配套改為 0 12px（AC2 + 決策 3）。
4. #submit-speaker-names-btn 全程沿用共用 .btn .btn-primary .btn-sm， 未新增任何專屬樣式（AC2）。
5. .seg-row 邊框改 --ds-border；.seg-time 顏色改 --ds-text-secondary、字體改 --ds-font-mono（Mono.code 13px/18px）； .seg-text 顏色改 --ds-text-primary、套用 Body.body（15px/28px）（AC3）。
6. .speaker-chip 只加 --ds-radius-pill（數值不變）與 caption 字級（13px），行內動態 background 指派邏輯完全不動，深色文字在六色色盤上仍清晰可辨（AC4）。
7. 手機 <480px：.seg-row 改為 flex-direction: column 三行式垂直堆疊 （時間 → 講者 chip → 文字），每行各自佔滿寬度，不再因固定 min-width 造成重疊或截斷（AC5， 對照左側 Before 象限的擠壓問題）。
8. 本原型未修改任何 JS 邏輯，所有互動皆為靜態展示；實際頁面行為（renameSpeaker() / submitSpeakerNames()）不受影響（AC6）。
