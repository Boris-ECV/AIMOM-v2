# Button

三種按鈕樣式：主要（Primary）、次要（Secondary）、文字（Tertiary）。全站不使用任何強調色，層級只靠背景與邊框的明暗區分。

## 何時使用哪一種

- **主要按鈕**：每個畫面／每個工具列最多一個，代表這個區塊最重要的動作（例如「匯出」）。背景使用 `ink-100`（或系統選定的其他 ink 深淺），文字為 `bg`。
- **次要按鈕**：其餘一般動作（「重新產生」「清除暫存」「+ 新錄音」）。白底、`border-strong` 邊框、`text-primary` 文字。
- **文字按鈕（弱化）**：權重最低、破壞性較低的動作。外觀同次要按鈕，文字改用 `text-secondary`。

## 規格

- 高度：桌面 `control-h-desktop`（40px）、手機 `control-h-mobile`（44px）。
- 圓角：`radius-sm`。
- 文字樣式：`label-button`（14px / 500）。
- Focus：鍵盤聚焦時顯示 2px `focus-ring` 外框，`outline-offset: 2px`；不可省略，這是目前唯一的鍵盤可視回饋。
- Disabled：不可互動時，透明度降至約 55%，游標改為 `not-allowed`，文字色改用 `text-placeholder`。
- 手機版：單一主要動作可設為全寬（`width:100%`）；多個按鈕並排時（如「清除暫存」「+ 新錄音」）改為 `flex:1` 等寬排列，不得並排到互相擠壓換行。

## 規則

- 一個畫面同時出現的主要按鈕不超過一個；不要用顏色以外的方式（如加粗、放大）製造第二個「主要」按鈕。
- 按鈕一律使用真正的 `<button>` 元素，不用 `<div onclick>`。
- 圖示：不加裝飾性 icon；「+ 新錄音」的「+」屬於文字內容，不是圖示。
