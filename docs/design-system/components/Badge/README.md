# Badge（狀態標籤）

用來顯示「這是系統狀態或提示」，例如「未提及，可手動填寫」「雙擊編輯」。**不是按鈕**，本身不可點擊、不觸發任何動作。

## 規格

- 背景 `badge-bg`、邊框 `badge-border`、文字 `badge-text`（皆為中性灰，刻意比按鈕更「安靜」）。
- 圓角 `radius-pill`（膠囊形），與按鈕的 `radius-sm`（直角圓角）明確做出區隔，避免使用者把標籤誤認成按鈕。
- 文字樣式 `caption`（13px）／手機 `caption-mobile`（12px）。
- 內距固定 `4px 12px`（桌面）／`4px 10px`（手機）。

## 規則

- 標籤不加 hover、cursor:pointer 或任何看起來可互動的樣式。
- 一組標題旁最多放一個標籤；需要多個狀態時，優先考慮改寫文案合併成一句，而不是疊加多個標籤。
- 標籤文字要簡短（建議 10 個字以內），過長的說明改放在旁邊的一般文字，不要塞進標籤。
