# Header（頁首）

所有頁面共用的頁首，桌面與手機版結構不同，兩者都要一併實作，不能只做桌面版。

## 桌面版（≥480px）

- 單列，高度 `header-h-desktop`（72px），背景使用系統選定的 ink 深淺（預設 `ink-100`）。
- 左側：系統名稱（可搭配一行副標，透明度降低）。
- 右側：導覽連結、帳號資訊（依序排列，透明度依重要性遞減）、登出按鈕（透明背景＋半透明白色邊框）。

## 手機版（<480px）

- 拆成兩列：
  1. 第一列（`header-h-mobile`，56px）：僅保留系統名稱＋登出按鈕，避免標題被擠壓。
  2. 第二列（次要導覽列）：背景疊加一層 `rgba(0,0,0,0.14)`，把其餘導覽連結與帳號資訊放進可橫向捲動（`overflow-x:auto`）的一列，讓內容不必截斷或換行也不會撐爆版面。

## 規則

- 頁首不可在手機版直接把所有連結塞進同一列並縮小字級；一旦超過兩三個項目就必須拆成兩列或改用橫向捲動。
- 不加漢堡選單 icon；導覽連結在手機版一律以文字形式排列。
- 登出按鈕在任何寬度都必須維持可點擊／可 Tab 到的 `<button>`。
