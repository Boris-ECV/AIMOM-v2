# Card（內容卡片）

系統中所有內容區塊（會議資訊、摘要，以及未來的清單、統計區塊等）的標準容器。

## 規格

- 背景 `surface`（純白）、邊框 1px `border`、圓角 `radius-md`。
- 內距：桌面 `space-6`（32px）、手機 `space-5`（24px）。
- 卡片與卡片之間的垂直間距：`space-5`（24px）。
- 不使用陰影（box-shadow）做為卡片的視覺區隔，一律靠 1px 邊框；這是本系統「靠邊框、不靠陰影」的固定做法，新元件也應遵循。
- 卡片標題使用 `h2` 樣式；若卡片右上角需要狀態說明，放置一個 Badge（見 Badge 元件），不要用第二個標題或圖示。

## 規則

- 卡片內距若因手機版變窄導致標題與標籤擠在一起，允許標題列 `flex-wrap:wrap`，讓標籤換到下一行，但不可縮小字級硬塞在同一行。
