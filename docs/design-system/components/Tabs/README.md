# Tabs（分頁切換）

用於同一頁面內切換不同內容視圖（例如「會議紀錄」／「逐字稿」）。

## 規格

- 目前分頁：文字色 `ink-100`（隨系統選定的主色深淺變動）、字重 600、底線 2px `ink-100`。
- 非目前分頁：文字色 `text-secondary`、底線透明、字重維持 `label-button` 預設。
- 分頁列底部有一條 `border` 分隔線貫穿整列。
- 分頁間距 `space-6`（32px，桌面）；手機版分頁改為等寬（`flex:1`），不使用固定間距，避免文字被壓縮。

## 規則

- 分頁數量建議 2–4 個；超過時改用下拉選單或其他導覽方式，不要讓分頁列換行。
- 分頁一律用 `<button>` 實作並可用鍵盤 Tab／Enter 操作，不用純文字加 onClick。
